# Nighttime fireflies

Current glow, tiny winged lanterns, warm ink glimmers, and no fireflies. All use the engine's eight drifting positions and pulse timing over the same Meadow background and renderer midnight tint. Explicit logical-size compositing keeps effects aligned at high DPI. Character motion is scripted; terrain light emitters and audio are omitted. Production is unchanged.

Build: `node docs/mockups/firefly-cues/build-study.mjs`. Serve `test-results/firefly-static` with Vite preview.
