# Scared sweat comparison

Four options: Current drop, Chunky inked drop, Two sweat flecks, No overlay.

Open `index.html` through Vite. Compare all 19 characters, normal fall and fast stomp, optional pose echoes, left facing, night background, native size and 2x detail. Timeline can be scrubbed or played at normal or slow speed.

Production applies scared when downward velocity exceeds 400 and the expression is normal. Angry and protected/dizzy expressions can suppress it. This study forces scared during the scripted descent (0.3–1.6 seconds) to compare the overlays independently.

The current expression and fast-stomp echo geometry are frozen from main dd4e7164. The study uses real plush atlases and character sizes through a small drawing adapter: normal falls use jump pose; fast stomps use stomp pose. Echo visibility is independent of that pose choice. Scripted travel is not gameplay physics. Landing effects, squash, body lean and production lighting are omitted.

Rebuild: `node docs/mockups/scared-sweat/build-study.mjs`. Frozen baselines are retained on rebuild. Browser verification: `node docs/mockups/scared-sweat/verify.mjs` against port 4247. Captures are generated by the verifier. This batch changes no production effects.
