# Meadow petals

Current, notched blossom petals, folded ink petals, and no petals. Match 12 petals at original 2–4px size and drift/rotation ranges; 18 selected ink-edged leaves remain identical in every sample. Draw through the actual weather layer. Scripted particles and character motion; day/night views, no audio or terrain light emitters. Production unchanged.

Build `node docs/mockups/meadow-petal-cues/build-study.mjs` and serve `test-results/petal-static` with Vite preview.

The 8× detail strip uses the same shape renderer as the full scene.
