# Saturday morning UI assets

Portraits are 160 × 160 transparent PNG exports of the first 480 × 480 cell from each approved 1920 × 960 expressive character atlas in `docs/mockups/character-roster-expressive/`. They are shared by React menus and the canvas HUD, decoded once per renderer realm. They do not replace gameplay sprites.

`random-preview.svg` is the approved Random arena illustration; `meadow-preview.png` is the existing Meadow scene preview. Lobby level scenery is unchanged by this UI implementation.
